# PPTX Builder — description

A local-first converter that turns PDFs and image folders into clean, size-controlled PowerPoint presentations without uploading a single file.

Online converters require you to upload your documents and then hand back fragile "editable" results that fall apart on anything complex. PPTX Builder refuses both: it processes entirely on your own machine and produces consistent raster output you control. It renders PDFs or organizes image folders into one-slide-per-page decks with configurable DPI and encoder, a range of aspect ratios and paper sizes, and fit-or-fill placement, handling batch and recursive folders. Output size is the lever most converters hide: PPTX Builder exposes both halves of it, so a 43-page deck is 14 MB at the defaults or 83 MB in lossless PNG at 300 DPI, and the choice is yours rather than the tool's. The primary interface is a pip-installable Python CLI, with an optional Gradio web UI and a Docker deployment carrying environment-variable limits for self-hosted instances. The problem it solves is small and common — private, predictable document-to-slides conversion — and it solves it without asking you to trust a server.

Python 3.8+ with python-pptx, Pillow, PyMuPDF, pdf2image, pillow-heif, and tqdm; optional Gradio web UI; Docker-deployable with poppler-utils. Published to PyPI as sageframe-pptx-builder (v0.3.0), which made the page encoder configurable — `--format`, `--quality`, and `PPTX_FORMAT`/`PPTX_QUALITY`/`PPTX_DPI` — and moved the defaults to 200 DPI JPEG q85. A capped public demo runs at pptx.sageframe.net; an uncapped instance runs on the homelab at pptx-full.sageframe.net.
