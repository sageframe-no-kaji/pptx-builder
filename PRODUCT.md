# Product

## Register

product

## Users

Tech-savvy people who need fast, private PDF/image-to-PPTX conversion — designers, presenters, developers using it as a utility. Comfortable with both web interfaces and CLI tools. Not a general public audience; these are people who know what they want and resent getting in their way.

## Product Purpose

A free, private, no-nonsense converter that turns PDFs and images into PowerPoint presentations. The web UI is a demo surface that demonstrates the capability and points to the CLI and GitHub for power users who want the full tool. Success looks like: user uploads, converts, downloads, and optionally discovers the CLI — all in under a minute with zero friction.

## Brand Personality

Craft · Private · Considered

Understated, not performative. Built by a specific person with taste, not by a committee trying to maximize signups. The tool does one thing well and doesn't apologize for being simple. Documentation for power users lives alongside a frictionless path for the casual user.

## Anti-references

- **SaaS conversion tools** (Smallpdf, ilovepdf): cookie-cutter blue/orange palette, feature badge grids, "2M users" social proof, upsell banners. This tool has none of that.
- **Enterprise dark-mode dashboards**: obsidian + neon accent. Tool-for-tools aesthetic that signals complexity without delivering it.
- **Generic Gradio default skin**: the orange/teal Gradio theme that announces "Python AI tooling demo." The ATM brand system completely replaces this.
- **Gradient-heavy startup landing pages**: glassmorphism, gradient blobs, hero metrics, design as performance. This surface is about function, not fundraising.

## Design Principles

1. **Function is the brand.** The UI's job is to disappear. If the user is thinking about the interface, something is wrong.
2. **Signal craft through restraint.** The ATM brand system — warm ground, considered type, terracotta as the only interactive color — carries the brand identity. No decoration on top of it.
3. **Documentation for the curious, friction-free for everyone else.** Power-user info (CLI install, GitHub link, format list) is present and findable but never in the way.
4. **This is a demo, not a product.** The page's job is conversion + discovery: convert a file, then point to GitHub. Design for that path.
5. **Private by default, visible by behavior.** The privacy story (no storage, auto-delete) is a feature — surface it once, clearly, not repeatedly.

## Accessibility & Inclusion

WCAG AA. Keyboard-navigable form. No motion that can't be disabled. Sufficient contrast throughout using ATM brand system colors — never muted gray on near-white.
